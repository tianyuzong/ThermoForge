# README 图像说明

本目录保存仓库 README 使用的静态截图与结果对比图，采用相对路径引用，可直接在 GitHub 阅读。

## 来源

- 界面截图采集日期：2026-09-21。
- 示例：`power_module_heatsink.step` 功率模块散热安装座，180 × 120 × 44 mm。
- 截图来自同一个已完成的五工况任务，展示真实页面和已保存结果；截图过程仅读取结果，没有重新规划、运行或修改仿真参数。
- 材料、几何选区、热源和边界条件见根目录 README 的五工况 Prompt Demo。示例物性与换热系数用于工程初筛，不是材料认证数据或 CFD 风场结果。
- 原始模型、节点场、完整报告与本机数据目录未随截图提交。新安装的实例须导入模型并完成计算，才能使用对应的交互页面。

## 对比图的读法

正常风冷稳态基准采用 6 mm 网格、150 W 热源、45℃ 环境、鳍片换热系数 60 W/(m²·K)。停风工况继承其完整末帧温度场，鳍片换热系数改为 8 W/(m²·K)，其余热源条件保留，计算 600 秒。

- 有风稳态最高温度：76.0041℃；体积平均温度：68.7785℃。
- 停风 600 秒最高温度：133.7579℃；体积平均温度：126.2605℃。
- 最高温度之差：57.7538℃。
- 接触面最高温度达到 100℃ 的保存帧区间为 190–200 秒，线性估计约 198.59 秒。

有风虚线是稳态值的恒定参考；停风曲线是已计算的瞬态结果。对比图是结果后处理图，不表示界面已有一个同步双工况播放器。双视角动画截图的左右两幅则属于同一个工况，分别显示绝对温度与相对当帧最低温的温差。
